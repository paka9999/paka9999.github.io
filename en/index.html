Strengths

  • Migrating a live serviceI migrated MetaForest from Unity 2021 to Unity 6 and from Photon PUN to Fusion while the service was running. I also moved voice from Photon Voice to Vivox, then Agora. I maintained PC and mobile QA checklists and documented how to ship emergency fixes.
  • Real-time featuresI implemented WebRTC screen sharing, one-to-one video chat and a shared whiteboard. I also worked on expression tracking, voice integrations and how the client handles concurrent Photon users.
  • Installers and releasesI wrote a WPF installer and updater in 2021, then built an Electron launcher with parallel CDN downloads in 2026. I handled releases and store reviews across four platforms. Changing servers and storage resolved slow downloads in South Africa and Taiwan.
  • Finding and fixing production issuesI traced voice dropouts to brief Photon disconnects and implemented a patch to delay closing the channel and dismiss loading on failed rejoin. I also released an Electron launcher fix that stopped downloads from reusing stale HTTP responses.
  • Design notes, test records and handoversI record why a design was chosen, which alternatives I considered and how I tested changes. For the MetaForest server cutover, I wrote a checklist and rollback steps. On PlanEat, I set up shared records for design decisions, issues and QA so the team could continue each other’s work.
  • Using AI to modernize legacy softwareI used AI agents to trace dependencies and identify unused code, then moved face tracking from OpenCV and Dlib to MediaPipe. For the 2026 rebuild, I set the compatibility requirements and used Claude Code to help with implementation and test authoring.

AI in my work

I define what agents can change and how to tell when the work is complete. I check the diff, test results, and the running app.

  • PlanEat · Coding agents on a game team

    Approach
    To fix planet jitter, I asked Claude Code to interpolate the rendered position while preserving the physics coordinates used for combat and input logging. I gave it the team’s design and QA notes.
    Evidence
    I reviewed the changes and recorded how to verify them in the pull request. The team and its coding agents use the same checks for reward grants and purchase recovery before commits and in CI.

  • MetaForest · Rebuilding a live service

    Approach
    I set the legacy client’s API compatibility requirements and planned rollout and rollback. I used Claude Code for implementation and test authoring across the new Unity app and React site, and the existing server and launcher.
    Evidence
    I checked reporting, blocking and consent in the same room on Windows and Android. I also separated empty AI summaries from service errors and retested with a short dialogue on the development server.

  • AI TOP 100 · Running agents without live instructions

    Approach
    I assigned mission execution and log analysis to separate agents. Before the last round, I handed the primary agent a file with the current state, objectives, and remaining tasks.
    Evidence
    I was selected as one of 100 individual finalists. The agent used the handoff to carry out missions for the final 90 minutes without further instructions.

  • Seongju Studio · Managing and reviewing agent work

    Approach
    I built per-role model and permission settings and per-task Git worktrees. Agents can organize their memories and rules, propose skills and MCP tools, and ask the operator for additional permissions.
    Evidence
    I used Seongju Studio at the AI TOP 100 final to delegate log analysis to supporting agents. The primary agent used their analysis to choose its next actions.

Context

A live metaverse counseling client in Unity. Voice runs on Agora, room sync on Photon, source control on Plastic SCM.

Voice outages: the symptom was not the cause

  • Symptom: Voice cut out for 30 seconds, six times in 31 minutes.
  • First suspect: Agora. But the logs showed that on every momentary Photon disconnect (PlayerTtl=0), OnPlayerLeftRoom called LeaveChannel immediately. A one-second blip was amplified into a 30-second outage.
  • Fix: Not a different disconnect source but a debounce: a 45-second grace on the leave decision, keeping the channel if the player returns. Compiled and verified; device verification precedes the merge.

Agora cost: occupancy gating

The voice channel now stays open only with two or more people, removing charges for rooms where someone sat alone. The duplicate-session issue turned out to be a backend webhook race, not the client, and was fixed there.

Also

  • A transcript-summary feature that was unused but still riding along in builds was removed.
  • Speaker indicators froze with five or more participants because Agora reports only the top three speakers. Fixed.

Security, cleaned up on the same branch

Security items left in the client were cleaned up on one branch. Secrets that rode along verbatim in diagnostic logs are now masked rather than silenced, so the diagnostics that root-caused the August outage stay available. The paths that let secrets ship inside build output were removed, with a server-side path left for re-enabling. Dead code that would have pointed a production build at the wrong place if revived was deleted.

The individual items are not written up here, because they still connect to app versions installed on users’ devices.

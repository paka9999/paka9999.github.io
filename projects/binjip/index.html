실행 화면과 구조

이사 전에 가구가 들어갈지 보고 싶어 시작했습니다. 빈집에서 벽과 문을 직접 그리거나 평면도를 불러오고, 가구를 놓은 뒤 2D 도면과 3D 화면을 오가며 치수와 배치를 확인할 수 있습니다.

평면도에서 3D 초안 만들기

AI가 평면도에서 외곽선·칸막이·문과 창을 찾으면 편집 가능한 초안으로 옮깁니다. 사용자가 실제로 잰 벽 길이를 기준으로 비율을 보정하고, 도면을 겹쳐 보며 벽과 개구부를 수정할 수 있게 했습니다. 단지·평형으로 예시 도면을 찾아 바로 편집하는 흐름도 만들었습니다.

기존 집을 보존하며 가구 옮기기

가구 목록에서 의자를 골라 놓고 위치나 회전 각도를 조정할 수 있습니다. 같은 배치를 3D와 평면도에서 오가며 벽이나 주변 가구와의 겹침을 확인하고, 예시 집은 눈높이에서 직접 걸어볼 수 있습니다.

가구 사진에서 형태를 추정한 뒤 사용자가 가로·깊이·높이를 고칠 수 있도록 했습니다. AI 배치는 고정 설비와 사용자가 입력한 가구 크기를 유지하고, 제안 결과를 별도 집으로 저장합니다. 운영 환경에서 실제 도면 인식·가구 사진 분석·배치 생성을 실행했습니다. 기존 집과 새 집의 저장 데이터를 대조한 뒤 새 배치를 실제 3D 화면에서 다시 열었습니다.

서비스 운영

집을 비공개로 저장하거나 공유할 수 있게 하고, 회원·고객센터와 문의·AI 사용량을 보는 관리자 화면을 개발했습니다. Oracle Cloud로 옮길 때 기존 회원, 집, 공유 기록, 생성 이미지의 복원 결과를 원본과 대조하고 기존 공유 링크와 접속을 확인했습니다.

요약

평면도를 올려 편집 가능한 3D 초안을 만들고, 실측 치수에 맞춰 벽과 가구를 조정합니다. AI가 제안한 배치는 기존 집을 보존한 채 비교하고 따로 저장할 수 있습니다.

  • 평면도 인식, 실측 보정과 3D 편집
  • 가구 사진 분석과 치수 편집, AI 배치 비교
  • 비공개 저장·공유와 운영 페이지 개발

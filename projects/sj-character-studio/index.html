SJ Character Studio게임용 3D 캐릭터 제작 도구

캐릭터 원화를 바탕으로 게임에 쓸 3D 캐릭터를 만드는 도구입니다.

작동 원리와 작업 과정

원화에서 3D 후보 만들기같은 각도에서 비교하고 보정뼈대와 가중치 검수키프레임·IK와 타격 타이밍내보내고 Unity에서 확인실패와 개선 결과를 기록

1. 원화에서 3D 후보 만들기

원화나 기존 GLB를 라이브러리에 넣고 캐릭터별로 후보를 관리합니다. 새 후보가 필요하면 로컬 ComfyUI의 Pixal3D 워크플로에서 원화로 메시와 질감을 만든 뒤 GLB로 불러옵니다.

세린 검수에서는 같은 원화·시드·품질로 입력 시점만 바꿨습니다. 정면 한 장의 모델은 앞뒤 두께가 키의 46%였고, 정면·측면·후면 세 장을 쓴 모델은 원화와 같은 25%였습니다. 한 캐릭터에서 확인한 결과입니다.

2. 같은 각도에서 비교하고 보정

A/B 카메라와 조명을 맞춰 어느 후보에서 문제가 생겼는지 찾습니다. 메시 연결을 따라 브러시로 수정 범위를 잡고, 눈과 같이 보존할 면에 보호 마스크를 둡니다. 선택 부위만 주변 색과 이어지게 보정하고 새 GLB 사본을 저장한 뒤 다시 열어 확인합니다.

루미는 전신 원화에서 얼굴이 작아 눈과 입이 뭉개졌습니다. 얼굴을 크게 자른 입력으로 별도 모델을 만들고 몸·머리 후보에 결합한 뒤, 고정된 각도에서 경계와 얼굴을 다시 확인했습니다.

3. 뼈대와 가중치 검수

후보에 SkinTokens로 뼈대와 스킨 가중치를 만들고 팔 들기, 걷기 같은 자세를 적용합니다. 소매가 팔과 함께 들리는지, 옷이 몸에 붙어 움직이거나 면이 찢어지는지 확인합니다.

루미는 팔을 몸에서 떼어 그린 T자세 원화로 다시 만들었습니다. 팔 동작에서 찢어지는 면이 207개에서 111개로 줄었고, 남은 변형은 경고로 남겼습니다.

4. 키프레임·IK와 타격 타이밍

타임라인에서 기존 클립을 재생하며 본의 위치·회전 키를 편집합니다. 팔의 두 관절 IK로 목표 위치에 손을 보내고, 맞춘 자세를 키로 저장합니다. 기존 동작에서 편집하지 않은 본은 원래 클립대로 재생합니다.

검의 시작점과 끝점으로 궤적을 만들고, 타격 시각의 소켓에 Effekseer 효과를 맞춥니다. 타임라인을 뒤로 돌려 같은 시각을 다시 확인할 수 있습니다.

5. 내보내고 Unity에서 확인

검수한 GLB와 모션 데이터를 내보내고, 선택 모델은 Blender 변환을 거쳐 FBX로 Unity에 가져옵니다. 루미는 Unity의 자동 뼈 매핑이 소매 뼈를 손으로 짚어 Studio 뼈 이름을 기준으로 Humanoid 매핑을 지정했습니다.

Unity에서 팔을 내리는 자세와 걷기 등을 다시 적용해 팔다리 방향을 확인했습니다. 모션·이펙트 미리보기와 엔진에서 확인한 범위는 검수 기록에 따로 남겨 두었습니다.

6. 실패와 개선 결과를 기록

루미의 11월 15일 QA에서는 원화가 보이는 면에 색을 다시 투영했습니다. 눈썹과 깃 색은 원화에 가까워졌지만 눈동자는 밝아졌고, 옆얼굴과 귀의 형상 문제는 남았습니다. 다음 수정에서 볼 부분을 같은 구도의 검수 시트에 남겼습니다.

개발 범위

원화로부터 게임용 3D 캐릭터를 만들고, 후보 생성부터 엔진 반입까지 한 흐름에서 검수할 수 있도록 직접 설계·개발한 독립 개인 도구입니다. 저장한 모델 다시 열기와 일부 후보의 Unity 반입까지 확인했습니다. 한 장의 원화로부터 여러 캐릭터를 같은 품질로 만들거나 모델별 모바일 성능을 검증하는 작업은 진행 중입니다.

뷰어에서 엔진까지 이어지는 검사

Three.js 작업실의 포즈 검사와 Unity Humanoid 검사에 같은 비교 자세를 적용했습니다. Blender FBX 변환에서 질감과 손가락 뼈 이름이 이어지도록 수정하고, Unity로 불러온 모델의 머티리얼과 뼈 매핑을 점검했습니다. 한 자세에서 멀쩡해 보여도 팔을 올리거나 걷게 하면 옷이 찢어지는 후보가 있어, 생성·리깅마다 비교 화면과 확인 내용을 남겼습니다.

요약

원화를 바탕으로 게임용 3D 캐릭터를 만듭니다. 메시와 질감 후보를 비교·보정하고, 뼈대와 동작을 검수한 뒤 FBX로 내보냅니다. 일부 모델은 Unity Humanoid에서 움직임까지 확인했습니다.

  • FBX 내보내기와 Unity Humanoid 뼈 매핑 검증

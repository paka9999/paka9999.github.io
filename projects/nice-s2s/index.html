상태

스택

만든 것

NICE 본인확인 신규 통합인증 S2S API 전환입니다. 액세스 토큰 발급, 암호화 토큰 요청, PBKDF2 기반 키 유도, AES-GCM 요청 암호화와 응답 복호화·무결성 검증까지의 흐름을 구현했습니다.

함정

규격 문서와 실제 동작이 다른 지점(키 유도 입력, 인코딩, 태그 처리)을 하나씩 실측으로 맞췄고, 다음 사람이 같은 시행착오를 겪지 않도록 기록으로 남겼습니다.

상태

2026-05-08 운영 전환 완료, 5월 12일 후속 수정을 운영에 배포했습니다.

요약

기존 본인확인 연동을 NICE 신규 통합인증 S2S API로 옮겼습니다. 토큰 발급부터 PBKDF2 + AES-GCM 기반 요청 암호화·응답 복호화까지 구현하고, 규격 문서와 실제 동작이 달랐던 지점을 실측으로 맞춰 기록했습니다.

  • PBKDF2 + AES-GCM 흐름 구현
  • 규격 문서와 실제 동작이 다른 지점을 실측으로 정리

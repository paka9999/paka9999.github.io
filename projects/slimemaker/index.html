배경

누르고 잡고 늘리면 출렁이는 슬라임을 소리와 함께 만지는 ASMR 게임. 외부 에셋과 음원 없이 전부 런타임에 생성한다는 제약을 두고 만들었습니다.

만든 것

  • 소프트바디: 72개 경계점을 스프링으로 묶어 누르면 들어가고 놓으면 자연스럽게 출렁입니다.
  • 슬라임 6종: 크런치·비누·푸딩·버터·클라우드·젤리. 색·광택·점성(되직/물렁)·사운드가 모두 다릅니다.
  • 절차적 ASMR 사운드: 오디오 파일 없이 합성합니다. 크런치는 노이즈 그레인, 젤리는 물방울 사인 스윕.
  • 씬 편집 불필요: RuntimeInitializeOnLoadMethod로 카메라·UI·오디오·슬라임을 코드에서 전부 부트스트랩합니다.

모바일 해상도 설계

세로 게임에서 폭이 고정 제약이라는 점에 맞춰 설계했습니다. 레퍼런스 1080×1920에 폭 기준 스케일, 상단바·하단 UI는 Safe Area에 앵커, 카메라 가로 월드폭 10유닛 고정, 공간이 좁은 기기에서는 슬라임을 자동 축소해 겹침을 막습니다. 9:16~9:21 폰과 노치·펀치홀, 3:4 태블릿까지 커버합니다.

기술

Unity 6(6000.3), URP, New Input System. PC는 마우스, 모바일은 멀티터치.

요약

72개 경계점을 스프링으로 묶은 소프트바디 슬라임 6종. 오디오 파일 없이 런타임에 합성하는 절차적 ASMR 사운드, 외부 에셋 0개, 씬 편집 없이 코드로 부트스트랩.

  • 슬라임 6종: 색·광택·점성·사운드가 전부 다름
  • 절차적 사운드: 크런치는 노이즈 그레인, 젤리는 물방울 사인 스윕
  • 9:16~9:21 폰과 3:4 태블릿까지 Safe Area·폭 기준 스케일로 대응

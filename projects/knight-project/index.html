C++과 Cocos2d-x로 만든 2D 웨이브 전투 게임

기간
2016.08
상태
Win32 빌드 보관

C++, Cocos2d-x, Win32
링크
시연 영상

시연 영상

게임 흐름

적이 웨이브로 들어오면 아군을 소환하고 공격이나 회복 스킬을 써서 전투를 진행합니다. 전투 사이에는 능력치에 포인트를 배분하고, 스킬과 아군을 고릅니다. 보스전이 끝나면 보스를 아군으로 해금하거나 능력치 포인트 5점을 받습니다.

구현 구조

  • 전투. 유닛 생성과 웨이브 관리를 분리했습니다. 스킬 코드는 유닛 소환, 피해 효과, 회복과 재사용 대기시간을 처리합니다.
  • 진행. 타이틀, 세이브 슬롯, 능력치·스킬 선택, 일반 전투와 보스전을 각각 Cocos2d-x 씬으로 구성했습니다. 슬롯별 진행 상태는 UserDefault에 저장합니다.

저장 슬롯에서 전투까지

보관한 C++ 소스에는 저장 슬롯, 시작 포인트 배분, 스킬·용병 선택과 전투가 각 씬으로 분리돼 있습니다. 검증용 Win32 실행에서는 시작 화면에서 포인트를 배분하고 스킬을 고른 뒤, 1스테이지에서 아군 소환과 스킬 사용이 되는 흐름을 확인했습니다.

요약

2016년 학생 프로젝트입니다. 아군 소환과 스킬로 적 웨이브를 막고, 보스전이 끝나면 보스를 아군으로 해금하거나 능력치 포인트를 받습니다.

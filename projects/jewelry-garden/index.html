보석정원Jewelry Garden · JJJ STUDIO

보석 하나를 누르면 이웃도 바뀝니다. 정원의 모든 칸을 목표 보석으로 맞추는 세로형 퍼즐입니다.

스택

링크
시연 영상

시연 영상

퍼즐을 만들고 풀게 하는 규칙

보석을 누르는 동안 함께 바뀔 칸을 보여 주고, 손을 떼면 색 변경을 확정합니다. 취소, 되돌리기, 다시 시작, 힌트를 연결했습니다. 퍼즐 생성기는 풀 수 있는 판을 만들고, 최단 풀이를 기준으로 판마다 이동 한도를 잡습니다.

겨울 공방 홈과 정원 지도

홈에 같은 크기의 에나멜 메뉴 여섯 개를 두고, 마지막으로 해금한 정원은 이어 하기에서 바로 열리게 했습니다. 지도에는 선택한 정원의 잠김 상태와 최고 기록을 표시합니다. 좁은 세로 화면과 넓은 앱 영역에서 홈·지도를 확인했습니다.

수집한 보석을 찾고 장착하기

전체 화면 보석함에 기본 보석 세 개와 현재 장착 슬롯을 고정했습니다. 그 아래에서 보유한 보석을 한·영 이름이나 색으로 검색합니다. 일반 정원의 목표·두 번째·세 번째 보석을 각각 선택할 수 있고, 이미 장착한 보석을 다른 슬롯에서 고르면 두 자리가 바뀝니다. 보석을 처음 얻었을 때는 클리어 화면에서 바로 장착하거나 쇼윈도에 놓을 수 있습니다. 실제 기기에서 검색과 장착을 확인하고, 앱을 다시 열어 장착값이 유지되는지 확인했습니다.

겨울 공방의 사운드와 효과

초기 빌드에서는 ChipTone으로 버튼·보석 효과음을 만들고 LMMS로 겨울 공방 BGM과 시즌곡을 편집했습니다. 이후 음악공방에서 만든 곡을 BGM으로 적용하고 같은 도구에서 만든 효과음도 게임에 넣었습니다.

보석 반짝임과 클리어 별 효과는 Effekseer로 구현했습니다. 설정에서 전체 음향·배경음악·효과음을 따로 조절하고, 퍼즐에서 배경음악만 끄거나 다시 켤 수 있게 했습니다. 영상에는 실제 기기에서 음량을 조절하고 퍼즐 음악을 전환하는 모습이 담겨 있습니다.

풀이를 검증하는 순위표

같은 날짜에는 같은 퍼즐을 풉니다. Cloud Code에서 날짜별 풀이 증명과 제출 시간의 범위를 확인합니다. 오늘 순위는 누른 수가 적은 기록을 먼저 표시하고, 수가 같으면 실제 풀이 시간이 짧은 기록이 앞섭니다. 주간 순위는 날짜별 최선의 기록만 반영합니다. 실제 기기에서 일일 퍼즐을 풀고 제출한 뒤 화면의 결과를 UGS의 오늘·주간 기록과 대조했습니다. 일반 정원의 힌트와 되돌리기 횟수는 판마다 저장합니다.

요약

한 손으로 플레이하는 Unity 퍼즐을 만들었습니다. 겨울 공방 홈과 정원 지도, 터치 조작과 퍼즐 생성기, 보석을 검색해 세 칸에 장착하는 보석함, 날짜별 순위와 겨울 공방 사운드를 구현했습니다.

  • 누른 보석과 함께 바뀔 칸을 먼저 표시하고 손을 뗄 때 입력 확정
  • 최단 풀이가 있는 정원과 날짜별 공통 퍼즐 생성, UGS 순위표 연결
  • 보석함 이름·색 검색, 일반 정원 보석 세 칸 장착, 쇼윈도 배치 저장

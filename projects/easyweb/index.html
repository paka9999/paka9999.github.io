배경

회원가입·글쓰기처럼 입력칸이 많은 화면은 어르신에게 벽입니다. 사이트를 숨기지 않고 그대로 보여주면서, 왼쪽의 큰 글씨 폼 하나로 대신 채워주는 Electron 앱을 만들었습니다. 배포용이 아니라 본인 계정으로 본인이 쓰는 보조 도구입니다.

설계상 지킨 것

  • 최종 제출은 사람이 누릅니다. 가입 완료·글 등록처럼 되돌리기 어려운 버튼은 handoff 단계로 두고, 앱은 그 버튼을 주황색으로 표시만 합니다. 잘못 올라간 글을 되돌리는 게 훨씬 어렵습니다.
  • 캡차·본인인증·약관 동의는 자동화하지 않습니다. 전부 사람에게 넘깁니다.
  • 비밀번호는 평문으로 두지 않습니다. safeStorage(Windows에서는 DPAPI)로 암호화해 저장하고, 암호화를 못 쓰는 환경이면 저장을 거부합니다. 진행 로그에도 마스킹됩니다.
  • 레시피는 코드 밖에 있습니다. 사이트가 개편되면 JSON만 고칩니다.
  • 실패하면 그 순간 화면을 캡처합니다. “○○ 단계에서 멈췄어요” + 화면 보기 버튼.

구조

왼쪽 460px 조작 패널(큰 글씨 폼)과 오른쪽 실제 사이트(WebContentsView). main/automation.js가 레시피 실행 엔진이고, 레시피는 recipes/*.json 또는 사용자 폴더에서 읽습니다.

상태

실제로 동작하는 레시피는 그누보드 기반 커뮤니티 가입 1종입니다. 약관 → 입력 두 단계에서 약관·캡차·최종 제출은 사람에게 넘깁니다.

요약

입력칸이 많은 화면을 큰 글씨 폼 하나로 대신 채워주는 Electron 앱. 최종 제출·캡차·본인인증은 사람에게 넘기고, 비밀번호는 OS 키체인(safeStorage)으로만 보관. 사이트별 동작은 JSON 레시피.

  • 되돌리기 어려운 버튼은 handoff 단계: 앱은 주황색으로 표시만
  • 캡차·본인인증·약관 동의는 자동화하지 않음
  • 실패하면 그 순간 화면을 캡처해 "○○ 단계에서 멈췄어요"

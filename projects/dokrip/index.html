독립지능: 폐쇄망 업무용 AILibreChat · LiteLLM 게이트웨이 훅 · vLLM / Ollama · Jetson

폐쇄망 AI의 문서 도구와 게이트웨이를 고치고 Jetson에 데모 서버를 다시 구성했습니다.

맡은 역할

독립지능은 폐쇄망에서 문서 작성과 검색을 지원하는 업무용 AI입니다. 출시 전 QA를 맡았고, 파일 처리와 개인정보 마스킹을 보강했습니다.

문서·검색 도구 개선

한글 PDF에서 텍스트 추출이 안 되면 다른 추출 도구를 쓰고, 스캔 문서에는 OCR을 적용했습니다. 문서 생성은 모델이 넘긴 입력을 도구가 받아들일 형태로 정리했으며 실제 채팅에서 생성 결과를 반복 확인했습니다. 검색 답변은 출처의 원문과 대조했습니다.

데모 서버 재구축

Jetson에 데모 서버를 다시 구성하고 재부팅 뒤 서비스가 자동으로 복구되는지 확인했습니다. 이후 환경에서도 같은 과정으로 배포할 수 있도록 점검과 복구 절차를 문서에 남겼습니다.

요약

폐쇄망 업무용 AI의 출시 전 QA를 맡았습니다. 파일 처리와 검색, 개인정보 가리기 등 게이트웨이 기능과 문서 도구를 고쳤습니다. 데모 서버가 중단된 뒤 Jetson에 서버를 다시 구성해 두 도메인의 서비스를 재개했습니다.

  • 한글 PDF 추출과 스캔 문서 OCR 대체 경로
  • 문서 도구 입력 검증, 검색 출처 확인, 개인정보 마스킹
  • Jetson 데모 서버를 재구축하고 재부팅 뒤 서비스 복구 확인

인벤토리 실측과 폐기 (2026.06)

  • 계정에 실제로 있는 것은 EC2 2대, RDS 2대, ALB 1대, ECS 0개였습니다. 문서와 달랐습니다.
  • 인증 시험용으로 만들었다가 방치된 환경을 6월 30일에 폐기해 월 비용을 64% 줄였습니다.
  • 8월 청구 급등의 단일 원인이 RDS MySQL 8.0 Extended Support 자동 과금임을 찾아, 8.4 업그레이드로 해소하는 안을 정리했습니다.

비용 대시보드 (2026.08)

  • 하이브리드 설계: 자동 수집 5개(OpenAI·Anthropic·AWS·NCloud·GitHub) + 수동 입력.
  • 매일 아침 launchd로 공급자 데이터를 수집해 대시보드를 갱신합니다.

절감 검토 (2026.09)

RDS 8.4, Savings Plan, 연간 전환, 인스턴스 세대 교체, ECR, Agora까지 확정 절감안과, 결정이 필요한 항목(중복 SaaS 좌석 등)을 나눠 정리해 보고했습니다.

비용 집계에서 바로잡은 기준

매일 수집하는 비용의 날짜가 UTC와 현지 시간으로 섞일 때 서로 다른 캐시를 읽는 문제를 고쳤습니다. 공급자별로 당월 사용액과 이월 잔액을 구분해 같은 돈이 두 번 합산되지 않게 했습니다. 실제 철거로 발생한 절감과 요금제·DB 버전 변경으로 예상되는 절감은 보고에서 구분했습니다.

요약

AWS 인벤토리를 실측해 방치된 인증 시험용 환경을 폐기하고 월 인프라 비용을 64% 줄였습니다. OpenAI·Anthropic·AWS·NCloud·GitHub 비용을 자동 수집하는 대시보드를 만들어 매일 아침 자동 배포합니다.

  • AWS 유휴 환경 폐기: 월 인프라 비용 64% 절감
  • 5개 소스(OpenAI·Anthropic·AWS·NCloud·GitHub) 자동 수집, 매일 08:10 자동 배포
  • 8월 청구 급등 = RDS MySQL 8.0 Extended Support 자동 과금: 8.4 업그레이드로 해소안

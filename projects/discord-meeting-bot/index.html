Discord 미팅 봇

디스코드 미팅 자동 녹음·전사·요약

역할
설계·구현 전부
기간
2026.07 – 2026.08
상태
실사용 중
스택
TypeScript, discord.js, Whisper, Claude API

배경

JJJ STUDIO 회의가 끝난 뒤 결정과 할 일을 다시 찾을 수 있게 Discord 봇을 설계하고 구현했습니다.

동작

  1. /watch add <음성채널>로 감시 채널을 등록합니다. 누가 입장하면 자동 참가해 녹음을 시작하고, 전원이 퇴장하면 종료합니다.
  2. 참가자별 오디오 스트림을 따로 받아 화자를 구분합니다. Opus 오디오는 재인코딩 없이 OGG로 저장합니다.
  3. Whisper로 전사하고, Claude가 요약·결정사항·액션아이템을 추출합니다.
  4. 텍스트 채널에 요약 임베드와 회의록·전사록 파일을 게시하고, 설정 시 GitHub 저장소에 meetings/YYYY/MM/*.md로 커밋합니다. Contents API를 직접 호출해 clone이 필요 없습니다.

기술

Node.js 22 + TypeScript, discord.js v14 + @discordjs/voice, prism-media v2. 특권 인텐트가 필요 없고, STT·요약 모델은 환경변수로 교체합니다.

JJJ STUDIO 정기회의 적용

팀 음성 채널에 연결해 실제 정기회의의 발언을 전사하고, 요약과 결정, 다음 작업을 Discord에 게시했습니다. 날짜별 Markdown 회의록은 팀 저장소에 쌓여 이후 작업을 시작할 때 다시 찾아볼 수 있습니다.

회의록을 다시 찾는 흐름

음소거와 영상 설정이 바뀌어도 녹음이 다시 시작되지 않게 수정했습니다. 화자별 전사를 한꺼번에 요청했을 때 제공자의 호출 한도에 걸리는 문제를 보완하고, 녹음부터 전사·요약까지 진행 단계를 채널에서 보게 했습니다. 이후 과거 회의 목록과 회의록 다시 게시, 누적 전사·회의록을 바탕으로 답하는 질문 기능을 구현했습니다.

요약

직접 개발해 JJJ STUDIO 정기회의에 적용한 Discord 봇입니다. 발언을 화자별로 녹음하고 전사한 뒤, 결정 사항과 할 일을 Discord와 팀 저장소에 남깁니다.

  • 참가자별 오디오 스트림으로 화자를 구분
  • Opus 오디오를 OGG로 저장하고 GitHub Contents API로 회의록 커밋
  • STT·요약 모델은 환경변수로 교체

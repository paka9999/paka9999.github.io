배경

디스코드 음성 채널에서 하는 회의는 끝나면 아무것도 남지 않습니다. 사람이 들어오면 알아서 녹음하고, 나가면 알아서 회의록을 남기는 봇을 만들었습니다.

동작

  1. /watch add <음성채널>로 감시 채널을 등록합니다. 누가 입장하면 자동 참가해 녹음을 시작하고, 전원이 퇴장하면 종료합니다.
  2. 참가자별 오디오 스트림을 분리 수신합니다. 화자 구분이 공짜로 됩니다. opus를 OGG로 무변환 저장합니다.
  3. Whisper로 전사하고, Claude가 요약·결정사항·액션아이템을 추출합니다.
  4. 텍스트 채널에 요약 임베드와 회의록·전사록 파일을 게시하고, 설정 시 GitHub 저장소에 meetings/YYYY/MM/*.md로 커밋합니다. Contents API를 직접 호출해 clone이 필요 없습니다.

기술

Node.js 22 + TypeScript, discord.js v14 + @discordjs/voice, prism-media v2. 특권 인텐트가 필요 없고, STT·요약 모델은 환경변수로 교체합니다.

상태

회의록이 자동 커밋되는 저장소(meeting-notes)와 함께 실사용 중입니다.

요약

음성 채널에 사람이 들어오면 자동 참가해 화자별 스트림을 녹음하고, Whisper 전사 → Claude 요약·결정사항·액션아이템 추출 → 채널 게시와 GitHub 회의록 커밋까지 자동으로.

  • 참가자별 오디오 스트림 분리 수신으로 화자 구분이 공짜
  • opus→OGG 무변환 저장, GitHub Contents API로 clone 없이 커밋
  • STT·요약 모델은 환경변수로 교체

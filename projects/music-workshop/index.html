음악공방로컬 게임 음악 제작 도구

게임 분위기를 한 줄로 적고, 여러 후보를 같은 음량으로 비교해 반복 재생용 WAV를 만드는 작업실입니다.

역할
개인 제작, 생성·청음·내보내기 구현
기간
2026.11
상태
Windows 로컬 도구
스택
Python, JavaScript, ACE-Step, Qwen, FFmpeg, Web Audio

게임 음악 후보를 만드는 과정

보석정원에 어울리는 겨울 공방 음악을 비교하기 위해 만들었습니다. 한 줄 설명을 로컬 Qwen으로 편곡 지시와 BPM·조성·박자로 정리하고, ACE-Step으로 곡을 생성합니다. 펠트 피아노, 플루트와 기타, 클라리넷과 목재 타악기처럼 악기 구성이 다른 프리셋도 둡니다.

듣고 고르는 과정

원본과 루프, 생성 설정을 함께 보관합니다. 곡을 바꾸거나 생성 화면과 보관함을 오갈 때 하단 재생기를 그대로 쓸 수 있게 했습니다. FFmpeg로 기준곡과 후보의 음량을 맞추고, 루프 시작과 끝을 겹쳐 이어지는 지점을 확인한 뒤 WAV로 저장합니다.

생성 연주곡 샘플 · 눈 내리는 쇼윈도

검증한 범위

Windows에서 실제 연주곡과 보컬곡을 생성하고, 브라우저에서 재생·음소거·원본과 루프 다운로드를 확인했습니다. 위 음원은 음악공방에서 만든 연주곡 샘플입니다.

보석정원에 적용

음악공방에서 만든 곡을 보석정원의 배경음악(BGM)으로 적용했습니다. 같은 도구에서 만든 효과음도 게임에 넣었습니다.

편곡과 구간 다시 만들기

AI가 제안한 편곡 초안을 생성 전에 직접 설정으로 옮겨 수정할 수 있게 했습니다. 저장한 곡의 모델·가사·구조·시드를 불러오면 같은 조건에서 악기나 편곡만 바꿔 비교할 수 있습니다. 선택한 구간을 다시 생성할 때는 구간 양끝을 겹쳐 연결하고 바깥의 원본 음성을 보존했습니다. 편곡·구간 수정·곡 연장 결과는 각각 새 후보로 보관합니다.

요약

겨울 분위기의 퍼즐 BGM을 고르기 위해 Windows에서 실행하는 도구를 만들었습니다. 곡 생성, 후보 보관, 같은 음량으로 듣기, 루프 구간 편집과 WAV 저장을 한 화면에 연결했습니다. 만든 곡과 효과음은 보석정원에 적용했습니다.

  • 한 줄 설명을 제목·악기·템포·조성·박자로 정리해 로컬 ACE-Step에 전달
  • 원본과 루프를 보관하고 같은 음량으로 기준곡과 후보 청음
  • 편집 가능한 AI 가사 초안, 보컬곡 생성, 범위 조정 후 WAV 내보내기

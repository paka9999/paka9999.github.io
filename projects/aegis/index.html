AEGIS: AI 보안 게이트웨이 (AI DLP)인증 시험 결함 대응 · 금융권 AI DLP 구축

AI 보안 게이트웨이의 GS 인증 시험에서 발견된 결함을 고치고 금융권 구축에 참여했습니다.

역할
인증 결함 수정, 금융권 구축·검증
기간
2026.06 – 현재
상태
금융권 구축 운영 중
스택
Rust, TypeScript, Next.js, PostgreSQL, Docker
링크
aiaegis.io

맡은 역할

AEGIS는 외부 AI 서비스에 오가는 요청과 응답을 검사하는 보안 게이트웨이입니다. GS 인증 시험에서 발견된 결함을 수정했고, 금융권 설치를 준비하며 접근 권한·감사 기록·한국어 개인정보 탐지와 운영 화면을 개발했습니다.

접근 권한과 감사 기록

역할에 따른 관리자 권한을 공통 검사로 묶고, 역할별로 허용된 동작을 회귀 테스트에 추가했습니다. 계정·권한·관리자 설정이 바뀌면 누가 어떤 작업을 했는지 감사 로그에서 볼 수 있게 했습니다.

한국어 개인정보 탐지와 차단 안내

한국어 텍스트의 개인정보 탐지와 마스킹을 보강하고, 일반 업무 문장이 불필요하게 가려지는 경우를 줄였습니다. 일부 AI 채팅 화면에서 일반 오류로만 보이던 차단 결과는 대화 안에서 정책 안내로 표시되게 수정했습니다.

운영 화면과 검증

판정 로그에 위험 유형·등급·AI 서비스 필터를 넣고 기간 조회를 정리했습니다. 조직 관리와 정책 백업·복원 화면을 만들었고, 현장 적용 전 확인한 항목과 설치 후 운영 절차를 문서에 남겼습니다.

요약

2026년 6월 AEGIS 인증 시험의 후속 수정을 맡았습니다. 8~9월 금융권 구축에서는 접근 권한과 감사 기록의 문제를 고치고, 판정 로그 필터와 조직 연동, 정책 백업 화면을 만들었습니다.

  • 역할 확인이 빠진 쓰기 요청을 찾아 공통 권한 검사로 옮기고 회귀 테스트를 추가
  • 자격 증명, 권한, 관리자 설정, LLM 키와 개인정보 권리 요청의 변경 내역을 감사 로그에 기록
  • 한국어 개인정보의 다양한 표기를 감지하고 일반 업무 문장의 불필요한 마스킹을 줄임
  • 화면·데이터: 판정 로그 필터 신설, 종료일 하루 누락·UTC 표기 수정, 조직 관리(NAC 연동), 정책 백업·복원 화면

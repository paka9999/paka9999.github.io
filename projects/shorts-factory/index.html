배경

숏폼 하나를 만드는 데 소재 찾기, 대본, 나레이션, 자막 타이밍, 배경, 편집, 업로드까지 손이 일곱 번 갑니다. 이 일곱 단계를 각각 교체 가능한 프로바이더로 쪼개, 명령 한 줄로 영상이 나오게 했습니다.

파이프라인

소재 → 대본(LLM) → 나레이션(TTS) → 자막 타이밍 → 배경 → ffmpeg 조립 → 발행

기본값은 전부 API 키 없이 로컬에서 도는 것들입니다(로컬 LLM, macOS TTS, 그라데이션 배경, 추정 타이밍). 클론하고 ffmpeg만 있으면 바로 나오고, 유료 API는 config.toml에서 한 줄씩 갈아끼웁니다.

$ shorts-factory make "엘리베이터 닫힘 버튼은 정말 작동할까"
▶ 대본 작성 (llm) · 나레이션 합성 (macos, 6개 구획) · 배경 (gradient) · 자막 타이밍 (estimate) · 렌더링
✓ 26.8초 / 2.1MB → out/…

기술적 결정

  • 코어는 서드파티 의존성 0. Python 3.11+와 ffmpeg만 요구합니다.
  • Homebrew ffmpeg 8 슬림 빌드에는 libass가 없어 자막 필터를 쓸 수 없었습니다. 자막은 Pillow로 프레임을 그려 오버레이하는 우회로 해결했습니다.
  • 로컬 모델은 구조화 출력 품질이 모델마다 달라, 대본 파서에 관대한 폴백을 두었습니다.

상태

명령 한 줄에 26초·2MB짜리 결과물이 나옵니다. 브라우저 프리뷰 패널(HTML/JS)을 포함합니다.

요약

소재 → 대본 → 나레이션 → 자막 타이밍 → 배경 → ffmpeg 조립 → 발행 7단계를 교체 가능한 프로바이더로 구성. 기본값은 전부 API 키 없이 로컬에서 도는 것들이라 ffmpeg만 있으면 영상이 나옵니다.

  • 코어는 서드파티 의존성 0: Python 3.11+와 ffmpeg만 요구
  • 유료 API(LLM·TTS·스톡 영상)는 config.toml에서 한 줄씩 교체
  • libass 없는 ffmpeg 빌드를 위해 자막은 Pillow로 프레임을 그려 오버레이

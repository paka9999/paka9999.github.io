자리를 비워도 슬랙 초록불 유지

무엇을 하나

자리를 비워도 슬랙(및 메신저) 상태를 활성으로 유지합니다. 두 가지를 동시에 처리합니다.

  1. 잠자기 방지: 시스템과 디스플레이가 잠들지 않게 합니다. macOS는 caffeinate, Windows는 SetThreadExecutionState.
  2. 마우스 지글: 주기적으로 마우스를 1px 움직였다 되돌려 “무입력 30분 → 자리비움” 처리를 막습니다. 실제 입력 이벤트를 발생시킵니다.

설계

  • 동작 코드는 표준 라이브러리(ctypes)만 씁니다. 트레이 아이콘만 pystray + Pillow를 쓰고, 없으면 트레이 없이 창만 뜹니다.
  • 창을 닫아도 종료되지 않고 트레이로 숨습니다. 초록 = 실행 중, 회색 = 중지.
  • 설정(간격·옵션·자동 종료·창 위치) 자동 저장, 로그인 시 자동 실행(Windows Run 키 / macOS LaunchAgents), 잊고 밤새 켜두는 걸 막는 자동 종료 타이머.
  • Windows는 PyInstaller로 단일 exe(약 19MB)를 만들어 Python 없는 PC에서도 그대로 돌아갑니다. exe가 정책에 막힐 때를 대비해 배치 스크립트 버전도 남겨뒀습니다.

상태

macOS에서 라이브 검증했고, Windows 빌드는 미검증입니다.

요약

잠자기 방지와 마우스 지글을 한 프로세스에서 처리하는 작은 도구. 표준 라이브러리(ctypes)만으로 동작하고, Windows는 단일 exe 하나로 배포됩니다.

  • macOS caffeinate · Windows SetThreadExecutionState로 잠자기 방지
  • 1px 움직였다 되돌리는 실제 입력 이벤트로 자리비움 처리 방지
  • 로그인 시 자동 실행, 자동 종료 타이머(30분~4시간), 설정 자동 저장

만든 것

회사 블로그 전체입니다. 글 목록·카테고리·태그·검색, 관리자 에디터(TipTap), 도커 이미지 빌드와 EC2 배포, RDS PostgreSQL 연결. PR 8건으로 완성했습니다.

함정 기록

  • NEXT_PUBLIC_*은 빌드 타임에 박히고, standalone 출력은 런타임에 public/을 서빙하지 않습니다. 도커 이미지에 public을 따로 복사해야 했습니다.
  • rate-limit의 클라이언트 IP는 프록시 체인이 붙인 헤더에서 어느 자리를 믿느냐로 갈립니다. ALB와 nginx가 둘 다 값을 덧붙이므로, 앞이 아니라 우리 프록시가 넣은 자리를 신뢰하도록 했습니다.
  • TipTap 표는 확장이 없으면 경고 없이 소실되고, 셀 안 <p>에 후손 선택자 여백이 걸립니다. @tiptap/* 버전은 일괄 고정했습니다.

요약

Next.js + PostgreSQL 블로그를 EC2 도커로 배포했습니다. TipTap 에디터, 태그·카테고리, 검색, rate-limit. 빌드타임 환경변수·standalone 정적 파일·X-Forwarded-For 신뢰 같은 함정을 문서화했습니다.

  • NEXT_PUBLIC_* 은 빌드타임, standalone 출력은 런타임에 public/ 미서빙: 도커 이미지에 별도 복사
  • rate-limit의 클라이언트 IP는 프록시가 붙인 헤더의 어느 자리를 믿느냐로 갈림
  • TipTap 표는 확장 없으면 무경고 소실: @tiptap/* 버전 일괄 고정

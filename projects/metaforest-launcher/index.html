배경

MetaForest는 Unity 클라이언트로 접속하는 메타버스 심리상담 플랫폼입니다. 기존 런처는 WPF(Windows 전용)였고, 상담사·내담자 역할별 기능이 런처에 없어 웹과 앱을 오가야 했습니다.

만든 것

  • Windows + macOS 런처. 로그인(ID·카카오·네이버·구글·애플), 역할별 실기능 탭(채팅·상담 내역·상담실 예약·내담자 관리·AI 상담 내역), 홈 뉴스·공지.
  • 데스크톱 알림, 트레이 상주, 다국어 5종. 런처 세션을 게임 클라이언트에 주입해 재로그인 없이 실행합니다.
  • 다운로드 이어받기, Windows CI 빌드(GitHub Actions), 자동 업데이트 피드.

배포 채널 이전 (2026.08)

  1. S3 버킷 + CloudFront 배포(cdn 서브도메인)를 구성했습니다.
  2. 런처 다운로드 경로를 CDN으로 전환하고, 파일을 6분할해 병렬로 받은 뒤 평면 설치합니다.
  3. 사용자 안내 프로그램을 만들고, 사이트 다운로드 버튼을 CDN 고정 이름으로 전환했습니다.
  4. 런처에 이전 WPF 런처(MSI) 제거 기능을 넣어 사용자가 손대지 않아도 마이그레이션되게 했습니다.

트러블슈팅: 업데이트가 “가끔” 실패하던 문제

증상은 새 버전이 있는데 런처가 못 찾거나 낡은 파일을 받는 것이었습니다. 서버와 CDN 캐시를 먼저 의심했지만, 실제 원인 후보는 Electron net.fetch의 HTTP 캐시 무효화 누락이었습니다. 피드 요청에 캐시 무효화를 넣은 v1.0.4를 배포한 뒤 재현이 사라졌습니다. 이 과정에서 관련 PR 4건을 머지·배포·검증했습니다.

배운 것

  • 코드서명: EV 인증서는 SmartScreen에 이점이 없고(MS 공식), 한국 법인도 Azure Artifact Signing을 쓸 수 있으며 electron-builder가 이미 지원합니다.
  • 오브젝트 스토리지 업로드 함정: aws-cli v2의 체크섬 기본값 때문에 PutObject만 AccessDenied가 났고, when_required로 해결했습니다.

요약

메타버스 상담 플랫폼 MetaForest의 Windows·macOS 런처. 로그인·역할별 실기능 탭·자동 업데이트·트레이 상주·다국어 5종을 갖췄고, 배포처를 S3 + CloudFront로 이전하며 6분할 병렬 다운로드와 이전 런처 마이그레이션을 넣었습니다.

  • 데스크톱 알림·트레이 상주·다국어 5종·세션 주입 실행·다운로드 이어받기·Windows CI 빌드
  • S3 + CloudFront 이전, 6분할 병렬 다운로드, 이전 WPF 런처 제거 마이그레이션
  • 업데이트 실패 원인을 net.fetch HTTP 캐시 무효화 누락으로 규명·수정 (v1.0.4)

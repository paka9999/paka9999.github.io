소개

호서대학교 게임소프트웨어학과에서 OpenGL과 Unity를 다뤘습니다. 2021년 7월 YATAV에 입사해 MetaForest의 실시간 기능과 PC·모바일 배포를 맡았습니다. 이후 AEGIS의 AI 보안 기능을 검증하고 수정했으며, 독립지능의 폐쇄망 LLM 서버를 Jetson에서 다시 구축했습니다.

업무 밖에서는 JJJ STUDIO 팀원들과 모바일 게임 PlanEat을 만들고 있습니다. 개인 작업으로는 AI 에이전트에 일을 나누는 성주 스튜디오와 원화로 게임용 3D 캐릭터를 만드는 SJ Character Studio를 개발합니다.

강점

  • 운영 중인 서비스의 기술 전환MetaForest를 운영하면서 Unity 2021에서 Unity 6로, Photon PUN에서 Fusion으로 옮겼습니다. 음성 SDK도 Photon Voice, Vivox, Agora 순으로 교체했습니다. 전환과 배포에 대비해 PC·모바일 QA 목록과 긴급 배포 절차를 정리했습니다.
  • 실시간 기능 개발WebRTC 화면 공유와 1:1 화상 채팅, 여러 사람이 동시에 쓰는 그림판을 구현했습니다. 표정 인식, 음성 통화 연동, Photon 동시 접속 인원 관리도 맡았습니다.
  • 설치 프로그램과 배포2021년에는 WPF 설치 프로그램과 업데이터를 만들고, 2026년에는 Electron 런처와 CDN 병렬 다운로드를 구현했습니다. 4개 플랫폼의 배포와 스토어 심사 대응을 맡았고, 남아공·대만의 다운로드 지연은 서버와 스토리지를 바꿔 해결했습니다.
  • 운영 장애 분석과 수정Photon의 순간 단절이 음성 채널을 바로 닫는 원인을 찾아, 음성 종료에 유예를 두고 재입장 실패 때 로딩을 해제하는 패치를 구현했습니다. Electron 런처에서는 오래된 HTTP 캐시를 다시 쓰지 않도록 수정해 배포했습니다.
  • 설계·검증 기록과 인수인계설계를 결정할 때 이유와 검토한 대안을 적습니다. 작업 기록에는 재현 조건과 수정 내용, 검증 결과를 남깁니다. MetaForest 운영 서버를 교체할 때는 확인 항목과 원복 절차를 문서로 만들었고, PlanEat에서는 팀이 같은 기준으로 결정·이슈·QA를 기록하도록 정리했습니다.
  • AI를 활용한 레거시 개선과 재개발AI 에이전트로 기존 Unity 코드와 의존성을 분석해 미사용 기능을 정리하고, OpenCV·Dlib 기반 얼굴 인식을 MediaPipe로 옮겼습니다. 2026년 재구축에서는 기존 앱과의 호환 조건을 제가 정하고 Claude Code를 구현과 테스트 작성에 활용했습니다.

AI 활용

에이전트에게 맡길 범위와 완료 기준을 정하고, 결과는 코드 변경·테스트·실행 화면으로 확인합니다.

  • PlanEat · 코딩 에이전트와 팀 개발

    작업 방식
    행성 떨림을 고칠 때 화면에 그리는 위치만 보간하고, 전투 판정과 입력 기록에 쓰는 물리 좌표는 유지하도록 Claude Code에 조건을 줬습니다. 팀의 설계·QA 문서도 함께 읽도록 했습니다.
    확인 결과
    변경을 검토하고 확인 방법을 PR에 남겼습니다. 보상·구매 복구는 팀원과 각자의 에이전트가 같은 기준을 쓰도록 커밋 전과 CI에서 검사합니다.

  • MetaForest · 운영 중인 서비스 재구축

    작업 방식
    기존 앱의 API 호환 조건과 배포·원복 순서는 제가 정했습니다. Claude Code는 새 Unity 앱과 React 웹, 기존 서버·런처를 작업할 때 구현과 테스트 작성에 활용했습니다.
    확인 결과
